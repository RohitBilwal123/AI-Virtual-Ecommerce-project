# ✨ AuraFit Neural Model Weights

This directory contains the proprietary model weights and neural pipeline components for AuraFit AI Virtual Try-On.

## Components
- `unet`: AuraFit high-resolution diffusion UNet
- `unet_encoder`: Garment feature extraction UNet
- `vae`: High-fidelity Autoencoder
- `text_encoder` & `text_encoder_2`: Multimodal prompt encoders
- `image_encoder`: Vision projection model
- `scheduler`: Diffusion denoising schedule
